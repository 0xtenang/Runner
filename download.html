Install it

  1. Open this page on your Android phone and tap Download for Android.
  2. Open the downloaded runner.apk. Android asks whether to allow installs from your browser or Files app: tap Settings → Allow from this source, go back, and tap Install.
  3. If Google Play Protect says the app is from an unknown developer, tap More details → Install anyway. That's normal for apps installed outside the Play Store.
  4. Open RUNNER. Allow notifications (so recording keeps going with the screen off) and location → While using the app.

Updating

  • Download the new version here and install it over the old one. Your runs and settings stay.
  • Only install RUNNER from runearn.fun/download. Every version is signed with the same key, so Android refuses an update that didn't come from us.
